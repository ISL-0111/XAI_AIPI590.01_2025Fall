## Notebooks

### Import_Dirt_Cleaning_Example.ipynb
A comprehensive guide demonstrating multiple methods to import and display the `Dirt_Cleaning.png` image:
- Method 1: Using PIL (Pillow)
- Method 2: Using Matplotlib
- Method 3: Using OpenCV
- Method 4: Using IPython Display
- Includes example image analysis code

To use the notebook, ensure you have the required libraries installed:
```bash
pip install pillow matplotlib opencv-python
```
